# 臺灣 108 課綱國中小各領域指標與迷思診斷內建資料庫 (Taiwan 108 Curriculum K-9 Indicators & Misconception Database)

本資料庫彙整中華民國教育部發布之「十二年國民基本教育課程綱要」（108 課綱）總綱、國民中小學（第一至第四學習階段）各領域／科目之**學習表現編碼**、**學習內容編碼**、**國小基本學習內容（國語文、英語文、數學 `NC` 編碼）**、**19 項法定議題指標**以及**各科常見學生迷思概念（誘答設計庫）**，供「國中小教師考試部署小幫手」於【步驟 1️⃣】命題時精準對接課綱指標與設計高診斷力干擾選項。

### 2. 學習內容編碼結構（`主題代碼-學習階段-流水號`）

- **文字篇章 (`A`)**：
  - `Aa-I-1` ~ `Aa-I-5`：聲符、韻符、聲調、拼音規則與說話語調。
  - `Ab-I-1` ~ `Ab-IV-6`：字詞識寫、多音字、形近字、部首部件、六書造字原則（象形、指事、會意、形聲）、成語與熟語、文言字詞義。
  - `Ac-I-1` ~ `Ac-IV-3`：標點符號、基本句型（敘事、有無、判斷、表態）、複句關係（並列、承接、轉折、因果、假設、條件）、修辭技巧（譬喻、擬人、誇飾、排比、設問、映襯、借代、轉化）。
  - `Ad-I-1` ~ `Ad-IV-4`：自然段與意義段、篇章主旨與大意、順敘與倒敘、總分總結構、過渡與照應。
- **文本表述 (`B`)**：
  - `Ba-I-1` ~ `Ba-IV-2`（記敘文本）：記敘六要素（人、事、時、地、物、原因經過結果）、順敘法、倒敘法、插敘法、第一／第三人稱視角。
  - `Bb-I-1` ~ `Bb-IV-5`（抒情文本）：直接抒情、借景抒情、託物言志、借事抒情。
  - `Bc-II-1` ~ `Bc-IV-4`（說明文本）：定義說明、舉例說明、分類說明、比較說明、數字與圖表說明、因果科學說明。
  - `Bd-III-1` ~ `Bd-IV-3`（議論文本）：論點、論據（事實論據、道理論據）、論證方法（舉例、正反對比、因果論證）。
  - `Be-I-1` ~ `Be-IV-3`（應用文本）：卡片、便條、書信、啟事、通知、讀書報告、新聞報導、圖表資訊整合。
- **文化內涵 (`C`)**：
  - `Ca-I-1` ~ `Ca-IV-2`（物質文化）：各族群飲食、服飾、建築、交通與生態智慧。
  - `Cb-I-1` ~ `Cb-IV-2`（社群文化）：家庭倫理、節慶習俗、社會制度與歷史典故。
  - `Cc-I-1` ~ `Cc-IV-2`（精神文化）：民間故事、神話傳說、古典詩詞韻文、現代文學名家生命情懷。

### 3. 國語文常見學生迷思概念與誘答設計方向

1. **局部細節誤當全文主旨**：將文章中的單一舉例或第一段背景描述誤選為整段或全文大意。
2. **個人生活經驗覆蓋文本事實**：選項符合一般生活常識，但教材文本中並未提及或與文本設定相反。
3. **複句關聯詞邏輯誤判**：將「雖然……但是……」（轉折，重點在後句）誤判為因果關係或重點在前句。
4. **修辭格混淆**：將含有「好像、彷彿」的「猜測／非譬喻句」（如：天色陰暗，好像快下雨了）誤判為譬喻修辭；或將「擬物」與「擬人」混淆。
5. **字詞望文生義**：以字面單字意思拆解成語或文言詞彙，忽略上下文語境。

## 三、 語文領域－英語文 (`英-E` / `英-J`) 指標與迷思診斷庫

### 1. 學習表現與學習內容核心編碼

- **學習表現（`類別數字-階段-流水號`）**：
  - `1-II/III/IV`（聽）、`2-II/III/IV`（說）、`3-II/III/IV`（讀：辨識字詞、讀懂句意、擷取對話與短文重點、從上下文推敲詞義）、`4-II/III/IV`（寫）、`5-II/III/IV`（聽說讀寫綜合應用）、`6`（態度）、`7`（策略）、`8`（文化理解）、`9`（邏輯思考與判斷）。
- **學習內容（`主題代碼-階段-流水號`）**：
  - `Aa-II-1`~`Aa-II-2`：26 個印刷體大小寫字母辨識與書寫。
  - `Ab-II-1`~`Ab-IV-4`：字母拼讀規則 (Phonics)，子音、短母音、長母音、雙母音與複合子音。
  - `Ac-II-1`~`Ac-IV-4`：國小應用字彙（300 字）／認識字彙（500 字）；國中應用字彙（1,200 字）。
  - `Ad-II-1`~`Ad-IV-2`：國小核心句構（Be 動詞、一般動詞現在簡單式、現在進行式、助動詞 `can/do/does`、`Wh-` 與 `Yes/No` 問句、單複數名詞與介系詞 `in/on/under/at`）；國中核心句構（過去式、未來式、現在完成式、被動語態、比較級與最高級、不定詞與動名詞、連接詞與關係子句）。
  - `Ae-II-1`~`Ae-IV-5`：簡易歌謠韻文、對話、短文、書信、時刻表與圖表訊息。
  - `B-II-1`~`B-IV-8`：打招呼、感謝、道歉、請求、問路、購物、點餐、表達感受與意見。

### 2. 英語文常見學生迷思概念與誘答設計方向

1. **Be 動詞與一般動詞混用**：如誤選 `*He is like apples.` 或 `*Do you happy?`。
2. **第三人稱單數動詞變化遺漏或重複**：如誤選 `*She play baseball.` 或 `*Does he likes milk?`（助動詞後未還原原形動詞）。
3. **疑問詞與回答不匹配**：`Where`（地點）與 `When/What time`（時間）、`How many`（可數數量）與 `How much`（價錢／不可數）混淆。
4. **代名詞主格／所有格／受格混淆**：如將 `he / his / him` 或 `they / their / them` 在句中位置誤用。
5. **閱讀細節時間軸與人物張冠李戴**：對話中有兩人以上時，將 A 角色做的事或喜歡的事物誤配給 B 角色。

## 四、 數學領域 (`數-E` / `數-J`) 指標、國小基本學習內容 (`NC`) 與迷思診斷庫

### 1. 學習表現編碼結構（`類別小寫字母-學習階段-流水號`）

- **`n`（數與量）**：
  - 第一階段 (`I`，1~2年級)：`n-I-1`（千以內數的位值與化聚）、`n-I-2`（加減直式計算）、`n-I-3`（加減估算與應用）、`n-I-4`（乘法意義與十十乘法）、`n-I-5`（分裝與平分初步經驗）、`n-I-6`（認識單位分數）、`n-I-7`（長度）、`n-I-8`（容量、重量、面積直接比較）、`n-I-9`（時間：幾點幾分與報讀）。
  - 第二階段 (`II`，3~4年級)：`n-II-1`（一億以內數的位值）、`n-II-2`（熟練較大位數加減乘直式）、`n-II-3`（理解除法的意義與直式計算）、`n-II-4`（解決四則估算與兩步驟問題）、`n-II-5`（在具體情境中解決兩步驟問題）、`n-II-6`（理解同分母分數的加減、等值分數與簡單異分母比較）、`n-II-7`（理解小數的意義與加減）、`n-II-8`（能在數線標示整數、分數、小數）、`n-II-9`（理解長度、角度、面積、容量、重量的常用單位與換算）、`n-II-10`（理解時間的加減運算）。
  - 第三階段 (`III`，5~6年級)：`n-III-1`（理解數的十進位的位值結構，延伸至小數與大數）、`n-III-2`（在具體情境中，解決三步驟以上之常見應用問題）、`n-III-3`（認識因數、倍數、質數、最大公因數與最小公倍數）、`n-III-4`（理解約分、擴分、通分的意義，並應用於異分母分數的加減）、`n-III-5`（理解整數相除的分數表示意義）、`n-III-6`（理解分數乘法和除法的意義、計算與應用）、`n-III-7`（理解小數乘法和除法的意義與應用）、`n-III-8`（理解以四捨五入取概數）、`n-III-9`（理解比例關係的意義：比、比值、正比、百分率、折扣）、`n-III-10`（嘗試將較複雜的情境或模式中的數量關係以算式正確表述）、`n-III-11`（認識量的常用單位及其換算，並處理相關的應用問題）、`n-III-12`（理解容量、容積和體積之間的關係）。

### 3. 自然科學常見學生迷思概念與誘答設計方向

1. **實驗變因設定迷思（控制變因法）**：在驗證「某因素（操縱變因）對結果（應變變因）的影響」時，誤選同時改變兩個以上條件的實驗組別。
2. **植物生理迷思**：誤以為「植物在白天只行光合作用、晚上才行呼吸作用」（事實上植物日夜皆進行呼吸作用）。
3. **月相與日食月食混淆**：誤以為每個月的「月相盈虧（朔、上弦、望、下弦）」是因為地球的影子遮住月球（地球影子遮住月球是「月食」，僅發生在農曆十五望日且日地月近乎一直線時）。
4. **太陽方位與竿影迷思**：誤以為竿影方向與太陽方位相同（應為**相反**，如上午太陽偏東，影子偏西），或誤以為太陽高度角愈大竿影愈長（應為高度角愈大、竿影愈短）。
5. **水溶液與質量守恆迷思**：誤以為方糖溶解在水中後重量會減輕或消失（應為糖重＋水重＝糖水總重）；或誤以為溫度升高時所有氣體在水中的溶解度也跟固體一樣升高（氣體溶解度隨水溫升高而降低）。
6. **電路串聯與並聯迷思**：誤以為「兩顆電池並聯」會讓燈泡比一顆電池更亮（電池並聯電壓不變、亮度不變，但可維持發亮較久；電池串聯才會增加亮度）。

  - `3b-II/III/IV-1~3`：蒐集、整理、查證並判讀各類社會資料（含統計圖表、歷史史料、等高線地形圖、衛星影像）。

### 3. 社會領域常見學生迷思概念與誘答設計方向

1. **時空背景錯置（時代穿越迷思）**：在歷史情境題中，將不同時期的制度、建設或作物混為一談（例如：在荷西時期出現鐵路與縱貫線，或在清領前期出現皇民化運動）。
2. **地理季風與地形雨方向顛倒**：混淆臺灣冬季「東北季風」（迎風面為北部、東北部，中南部為背風乾燥區）與夏季「西南季風」。
3. **等高線地形圖判讀迷思**：混淆「河谷（等高線向高處彎曲，V 字尖端指向高處）」與「山脊（等高線向低處彎曲）」；或誤以為等高線愈密集代表坡度愈平緩（應為愈陡峭）。
4. **事實與觀點混淆**：無法區分史料中的「客觀歷史事實（時間、地點、人物行為）」與「作者主觀評價／歷史解釋」。
5. **公民法律責任混淆**：混淆「民事責任（損害賠償）」、「刑事責任（有期徒刑、罰金、拘役）」與「行政責任（罰鍰、吊銷執照）」，特別是「罰金（刑法）」與「罰鍰（行政法）」的區別。

### 2. 19 項法定議題實質內涵編碼速查表（跨領域文本命題對接用）

當教師提供的教材涉及跨領域議題（如防災宣導、食農環境、網路霸凌、原民文化、性別平權）時，可同步標註以下法定議題代碼（國小用 `E`、國中用 `J`）：

- **性別平等教育 (`性E1`~`性E13` / `性J1`~`性J15`)**：破除性別刻板印象、身體自主權、防治性騷擾與性別暴力、多元性別尊重。
- **人權教育 (`人E1`~`人E11` / `人J1`~`人J14`)**：兒童權利公約 (CRC)、生存與受教權、反歧視與反霸凌、隱私權與言論自由界線。
- **環境教育 (`環E1`~`環E17` / `環J1`~`環J16`)**：生物多樣性、氣候變遷與溫室效應、資源循環與減塑、綠色消費與永續發展。
- **海洋教育 (`海E1`~`海E16` / `海J1`~`海J20`)**：親海安全（離岸流防範）、海洋飲食文化、臺灣海岸地形、黑潮生態與海洋保育。
- **科技教育 (`科E1`~`科E7` / `科J1`~`科J9`) & 資訊教育 (`資E1`~`資E13` / `資J1`~`資J10`)**：運算思維、網路禮儀、個人資料保護、假訊息查證、智慧財產權與 AI 倫理。
- **安全教育 (`安E1`~`安E14` / `安J1`~`安J12`) & 防災教育 (`防E1`~`防E9` / `防J1`~`防J9`)**：交通安全（內輪差與視野死角）、水域安全（救溺五步：叫叫伸拋划）、火災逃生（小火快跑、濃煙關門）、地震避難（趴下、掩護、穩住）。
- **品德教育 (`品E1`~`品E7` / `品J1`~`品J9`) & 生命教育 (`生E1`~`生E7` / `生J1`~`生J7`)**：誠信負責、同理關懷、失落與悲傷調適、生命價值尊重。
- **法治教育 (`法E1`~`法E4` / `法J1`~`法J9`)**：規則與法律的公平性、無罪推定、契約精神與網路法律責任。
- **能源教育 (`能E1`~`能E8` / `能J1`~`能J8`)**：再生能源（太陽能、風力、水力、地熱）與非再生能源、節能減碳行動。
- **家庭教育 (`家E1`~`家E13` / `家J1`~`家J12`) & 生涯規劃教育 (`涯E1`~`涯E12` / `涯J1`~`涯J14`)**：家人溝通、家務平權、家庭飲食文化、自我興趣探索與職業世界認識。
- **多元文化教育 (`多E1`~`多E6` / `多J1`~`多J11`) & 原住民族教育 (`原E1`~`原E15` / `原J1`~`原J12`)**：原住民族傳統生態知識 (TEK)、歲時祭儀與歷史正義、新住民文化交流與跨文化理解。
- **閱讀素養教育 (`閱E1`~`閱E14` / `閱J1`~`閱J10`)、戶外教育 (`戶E1`~`戶E7` / `戶J1`~`戶J5`)、國際教育 (`國E1`~`國E12` / `國J1`~`國J12`)**。
